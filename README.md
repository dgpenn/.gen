This repository contains very basic scripts related to installation and setup of Arch Linux. Some notes are included as well.

## Git Setup

```bash
git config --global user.name "Dennis"
git config --global user.email "git@digitaldemons.net"
```

### Git Setup SSH Origin

Set SSH origin after cloning over HTTPS.

```bash
git remote set-url origin git@github.com:dgpenn/.gen.git
```
